<h3 align="center">Frametok</h3>

<p align="center">
  <a href="https://codebydante.github.io/Frametok/">
    <img src="readme-button.svg" width="280" alt="ABRIR FRAMETOK">
  </a>
</p>

**Frametok** permite descargar publicaciones públicas de TikTok. Guarda las fotos de un carrusel por separado o en ZIP, y reproduce o descarga el audio que lo acompaña cuando está disponible. Para videos, puedes descargar el MP4 o guardar su pista de audio en MP3.
